# PublicDomainM3U

A curated, open-source VOD (Video on Demand) M3U playlist dedicated exclusively to legally free, public domain movies and television shows. 

Most community IPTV lists focus on live television. **PublicDomainM3U** is built for on-demand viewing. Simply load the playlist URL into your favorite IPTV player ([OnlineM3U](https://onlinem3u.com)) and browse a categorized library of classic cinema.

## How to Use

To use these playlists in your IPTV player, copy the **Raw** URL of the `.m3u` files and paste them into your app as a new playlist/line.

* **Movies:** `https://raw.githubusercontent.com/onlinem3u/publicdomainm3u/main/movies.m3u`
* **Series:** `https://raw.githubusercontent.com/onlinem3u/publicdomainm3u/main/series.m3u`
